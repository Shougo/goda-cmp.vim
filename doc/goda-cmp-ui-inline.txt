INTRODUCTION                                 *goda-cmp-ui-inline-introduction*

This UI displays the first item inline, after the cursor.  It is a port of
ddc-ui-inline.

It uses a text property or |popup_create()| in Vim, and virtual text by
|nvim_buf_set_extmark()| in neovim.  On the command line, it uses a floating
window in neovim.  It shows the item in insert mode and on the command line.

When the item starts with what is typed, only the rest of it is displayed.

NOTE: It does not work if the completion menu is already
displayed (|pumvisible()| or |pum#visible()|).


==============================================================================
INSTALL                                           *goda-cmp-ui-inline-install*

Please install "goda.vim" and "goda-cmp.vim", and Go to build your
configuration.

https://github.com/Shougo/goda.vim
https://github.com/Shougo/goda-cmp.vim

The UI is the Go package "github.com/Shougo/goda-cmp.vim/ext/ui/inline",
which your configuration imports, with the Vim script of this plugin.

NOTE: The package moves to a repository of its own for goda-cmp.vim 1.0, and
its import path changes then.

EXAMPLES                                         *goda-cmp-ui-inline-examples*
>go
	import "github.com/Shougo/goda-cmp.vim/ext/ui/inline"

	b.AddUI(inline.New())
	b.PatchGlobal(cmp.Config{UI: "inline"})
< >vim
	inoremap <expr> <C-t> goda_cmp#map#insert_item(0)

	" Cancel
	inoremap <C-e> <Cmd>call goda_cmp#hide('Manual')<CR>
<
It suits a single candidate.  With "pum" (|goda-cmp-ui-pum.txt|) for
several, chosen by `DynamicUI`: >go

	b.AddUI(inline.New())
	b.AddUI(pum.New())
	b.PatchGlobal(cmp.Config{
	    UI: "pum",
	    DynamicUI: func(_ context.Context, _ sdk.Host,
	        a cmp.DynamicUIArgs) (string, error) {
	        if a.Context.Mode != "t" && len(a.Items) == 1 {
	            return "inline", nil
	        }
	        return "pum", nil
	    },
	})
< >vim
	inoremap <expr> <Tab> goda_cmp#ui#inline#visible()
	      \ ? goda_cmp#map#insert_item(0) : "\<Tab>"
<
When DynamicUI switches the UI, the one that showed the previous list is
hidden.

FUNCTIONS                                       *goda-cmp-ui-inline-functions*

                                                *goda_cmp#ui#inline#visible()*
goda_cmp#ui#inline#visible()
		Returns |TRUE| when the UI displays an item.


==============================================================================
PARAMS                                             *goda-cmp-ui-inline-params*

The parameters are given to the constructor in Go
(`inline.New(inline.Params{MaxWidth: 80})`) or set from Vim script with
"uiParams" (|goda-cmp-params|).

                               *goda-cmp-ui-inline-param-checkNextWordMatched*
checkNextWordMatched	(boolean)
		If it is enabled, the UI checks the word after cursor is
		matched: an item that starts with what is typed is displayed
		as the rest of it only when it ends with the word after the
		cursor.

		Default: v:false

                                          *goda-cmp-ui-inline-param-highlight*
highlight	(string)
		The highlight of the inline text.

		Default: "ComplMatchIns"

                                           *goda-cmp-ui-inline-param-maxWidth*
maxWidth	(number)
		The maximum width of inline word.

		Default: 200
