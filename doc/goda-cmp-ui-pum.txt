INTRODUCTION                                    *goda-cmp-ui-pum-introduction*

This UI uses pum.vim's popup menu.  It is a port of ddc-ui-pum.

It shows the candidates in insert mode, on the command line
(|goda-cmp-cmdline|) and in a terminal (|goda-cmp-terminal|).

pum.vim is configured in Vim script as usual: |pum#set_option()| and the
|pum#map#insert_relative()| family for the keys.  goda-cmp.vim sets no option
of pum.vim and maps no key.


==============================================================================
INSTALL                                              *goda-cmp-ui-pum-install*

Please install "goda.vim", "goda-cmp.vim" and "pum.vim", and Go to build your
configuration.

https://github.com/Shougo/goda.vim
https://github.com/Shougo/goda-cmp.vim
https://github.com/Shougo/pum.vim

The UI is the Go package "github.com/Shougo/goda-cmp.vim/ext/ui/pum", which
your configuration imports, with the Vim script of this plugin.

NOTE: The package moves to a repository of its own for goda-cmp.vim 1.0, and
its import path changes then.

EXAMPLES                                            *goda-cmp-ui-pum-examples*
>go
	import "github.com/Shougo/goda-cmp.vim/ext/ui/pum"

	b.AddUI(pum.New())
	b.PatchGlobal(cmp.Config{UI: "pum"})
<
From Vim script, among the UIs your configuration added: >vim

	call goda_cmp#patch_global(#{ ui: 'pum' })
<
The keys of insert mode: >vim

	inoremap <C-n> <Cmd>call pum#map#insert_relative(+1)<CR>
	inoremap <C-p> <Cmd>call pum#map#insert_relative(-1)<CR>
	inoremap <C-y> <Cmd>call pum#map#confirm()<CR>
	inoremap <C-e> <Cmd>call pum#map#cancel()<CR>
<
On the command line, map them with |:cnoremap| (see |goda-cmp-cmdline|).

In a terminal, pum.vim cannot insert while selecting
(pum#map#insert_relative() does nothing there): select, then confirm, which
sends the item to the job, replacing the typed part with <C-h>s (the shell's
erase character must be <C-h>, `stty erase ^H`): >vim

	tnoremap <C-n> <Cmd>call pum#map#select_relative(+1)<CR>
	tnoremap <C-p> <Cmd>call pum#map#select_relative(-1)<CR>
	tnoremap <C-y> <Cmd>call pum#map#confirm()<CR>
<

PARAMS                                                *goda-cmp-ui-pum-params*

The parameters are given to the constructor in Go
(`pum.New(pum.Params{Insert: true})`) or set from Vim script with
"uiParams" (|goda-cmp-params|).

                                                *goda-cmp-ui-pum-param-insert*
insert		(boolean)
		Insert the first item automatically.
		It is useful for manual completion.

		Default: v:false

FREQUENTLY ASKED QUESTIONS (FAQ)                         *goda-cmp-ui-pum-faq*

FAQ 1:                                                 |goda-cmp-ui-pum-faq-1|
	I want to use goda-cmp.vim's previewer in pum.vim's preview window.

FAQ 2:                                                 |goda-cmp-ui-pum-faq-2|
	The popup menu does not work in |command-line-window|.

------------------------------------------------------------------------------
                                                       *goda-cmp-ui-pum-faq-1*
Q: I want to use goda-cmp.vim's previewer in pum.vim's preview window.

A: pum.vim does not use goda-cmp.vim's previewer automatically.  Please set
|pum-option-previewer| to |goda_cmp#get_previewer()| and enable
|pum-option-preview|.  It needs a pum.vim that has the previewer option. >vim

	call pum#set_option(#{
	      \   preview: v:true,
	      \   previewer: 'goda_cmp#get_previewer',
	      \ })
<
See |goda-cmp-preview|.

                                                       *goda-cmp-ui-pum-faq-2*
Q: The popup menu does not work in |command-line-window|.

A: It is the limitation of |command-line-window|.  See |pum-faq-3|.

NOTE: The problem is fixed in neovim 0.10+.  But |command-line-window| is
special buffer.  You need to enable specialBufferCompletion
(|goda-cmp-config|).

                                                       *goda-cmp-ui-pum-faq-3*
Q: Do I need to add the |PumCompleteDone| event for the lsp source?

A: No.  The UI tells goda-cmp.vim which item was accepted, and the source
does what it needs (additional text edits, commands) itself.
